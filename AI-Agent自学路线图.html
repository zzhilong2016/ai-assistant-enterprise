环境准备与基础认知

对应 01–05 集 · 1 周

跑通第一个 LLM 调用，理解大模型能做什么、不能做什么。

知识点

LLM 基本概念、应用场景、API 调用、Gradio 快速搭界面

实操练习

  1. 注册一个大模型 API（OpenAI / Anthropic / 国内 DeepSeek、通义均可），用 Python 完成第一次对话调用
  2. 用 Gradio 给这个调用套一个 Web 界面

官方资料

  • Gradio 官方文档：gradio.app/docs
  • DeepSeek API 文档（国内低成本上手）：api-docs.deepseek.com
01

提示词工程

对应 04–05、47–53 集 · 1 周

写出结构化、可复用的提示词，理解提示词的边界（注入攻击）。

知识点

基本原则、提示词结构、万能框架（角色 + 任务 + 上下文 + 输出格式）、提示词自动化、提示词攻击与防御

实操练习

  1. 把一个模糊需求改写成结构化提示词，对比改写前后的输出质量
  2. 用 few-shot 示例控制输出为固定 JSON 格式

官方资料

  • Anthropic Prompt Engineering 文档（质量最高，推荐）：docs.anthropic.com
  • OpenAI Prompt Engineering Guide：platform.openai.com
02

大模型原理 — Transformer

对应 54–65 集 · 1–2 周

理解 Token、Embedding、注意力机制，知其所以然。做应用开发不必推导数学，但要懂概念。

知识点

Tokenization、Embedding、位置编码、Self-Attention、Multi-Head Attention、前馈网络、编码器/解码器

实操练习

  1. 用 transformers 库加载一个小模型，打印 tokenizer 的分词结果
  2. 调用 embedding 模型，计算两句话的余弦相似度（为 RAG 打基础）

一手资料

  • The Illustrated Transformer（Jay Alammar 经典图解）：jalammar.github.io
  • Hugging Face 免费课程：huggingface.co/learn/nlp-course
03

RAG 检索增强生成 ⭐

对应 16–31 集 · 2 周

独立搭建一个生产可用的 RAG 系统，理解"RAG 是工程问题不是算法问题"。

知识点

  • 基础流程：文档加载 → 分割 → 向量化 → 向量数据库 → 检索 → 增强生成
  • 检索原理：倒排索引、KNN、ANN 近似最近邻、聚类索引、PQ 乘积量化
  • 优化技巧：混合检索（向量 + BM25）、重排序（Rerank）、查询改写
  • 评估：没有评估就无法优化（RAGAS 等框架）

实操练习

  1. 用 LangChain + 一个向量库（Chroma / Milvus / FAISS 任选）给自己的笔记文档建知识库并问答
  2. 对比"仅向量检索"与"向量 + BM25 混合检索 + Rerank"的回答质量差异

官方资料

  • LangChain RAG 教程：docs.langchain.com
  • Milvus 官方文档（生产级向量库）：milvus.io/docs
  • RAGAS 评估框架：docs.ragas.io
  • NVIDIA RAG 概念解释：nvidia.cn
趋势提示：2026 年的新方向是 Agentic RAG —— 由 Agent 自主决定何时检索、检索什么，而不是固定流水线。学完基础 RAG 后可在阶段 5 之后回看。
04

LangChain 1.0 实战

对应 32–40 集 · 1–2 周

掌握 LangChain 1.0 的核心抽象 create_agent（模型 + 工具 + 系统提示词 + 中间件）。

⚠️ 版本提醒：LangChain 1.0 已于 2025 年底正式发布，与 0.x 是完全不同的包结构，核心围绕 Agent 抽象重建，构建在 LangGraph 之上。网上大量旧教程（LLMChain、AgentExecutor 等写法）已过时，务必以 v1 文档为准。

知识点

Model 与 Prompt、Agent 与 Tool、记忆（Memory / Checkpointer）、Middleware 中间件、生产部署

实操练习

  1. 按官方 Quickstart 做一个带自定义工具的 Agent（如天气查询、文件读取）
  2. 加上 InMemorySaver 让 Agent 拥有多轮对话记忆
  3. 开通 LangSmith 免费额度，给 Agent 加上调用追踪（Tracing）

官方资料

  • Quickstart（首选入口）：docs.langchain.com/oss/python/langchain/quickstart
  • Agents 概念文档：…/langchain/agents
  • v1 新特性与迁移指南：…/releases/langchain-v1
05

LangGraph 实战

对应 41–46 集 · 1–2 周

用图（Graph）的方式构建可控、可恢复、有人工干预的智能体系统。

知识点

StateGraph、节点与边、Checkpointer 持久化记忆、Human-in-the-loop（人机协作）、时间旅行（回溯状态）、多智能体协作

实操练习

  1. 官方 Quickstart：构建一个带计算器的数学 Agent（Graph API）
  2. 在图上加入 interrupt，实现"执行敏感操作前等人工确认"
  3. 用 langgraph-swarm 实现两个 Agent 之间互相转接（handoff）

官方资料

  • LangGraph Quickstart：docs.langchain.com/oss/python/langgraph/quickstart
  • LangGraph 产品页（架构理念）：langchain.com/langgraph
  • 多智能体 swarm 库：github.com/langchain-ai/langgraph-swarm-py
06

Agent 方法论与行业落地

对应 06–12 集 · 1 周

从"会写代码"上升到"会设计系统"。

知识点

Agent 开发指南、典型范式（ReAct、Plan-and-Execute 等）、核心能力与外围技术、多智能体协同、行业落地场景（客服、营销、数据分析）

实操练习

  1. 用一张架构图梳理你阶段 3–5 做过的项目：模型层 / 检索层 / 编排层 / 接口层各是什么
  2. 分析一个真实需求（如公司内部的问答客服），写出技术选型理由

参考资料

  • Anthropic《Building Effective Agents》（业界公认的 Agent 设计最佳实践）：anthropic.com
  • freeCodeCamp《How to Build a Multi-Agent AI System with LangGraph, MCP, and A2A》（2026 免费全书）：freecodecamp.org
07

综合项目实战

对应 13–15、79–94 集 · 2 周

做 2 个能写进简历的完整项目。

项目 A：企业级 RAG 智能客服

知识库构建 + 混合检索 + Rerank + Agent 编排 + 接入 IM（企业微信 / 飞书 / Web 均可）

验收标准：有评估指标（召回率、回答准确率）、有引用溯源、有兜底话术

项目 B：LLM 信息抽取

Prompt 设计 → 正则 / JSON 结构化 → 数据清洗 →（可选）微调小模型

验收标准：输出稳定为合法 JSON，抽取准确率达业务阈值

关于 Codex 部分（66–78 集）：属于工具使用技巧，边做项目边用即可，不必单独学。视频中"绕过短信验证码"这类内容不规范，请通过官方渠道注册使用。
★

学习建议

  1. 视频当目录，文档当教材：视频用来建立整体认知，具体 API 写法一律查官方文档——这个领域半年一变，视频录完即过时。
  2. 每阶段必须动手：上面的实操练习是最低交付物，只看不练等于没学。
  3. 善用 AI 辅助：可以让 AI 编程助手帮你装 LangChain 官方 Docs MCP，随写随查最新文档。
  4. 简历导向：阶段 7 的两个项目 + 一篇技术复盘文章，比"看过 748 集视频"有说服力得多。
